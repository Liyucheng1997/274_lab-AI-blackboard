# AI 黑板

一块带 AI 能力的网页黑板，支持数学和英语教学场景。

## 功能

**数学模式**
- 🖍️ 用鼠标/触屏在黑板上手写手绘
- ✨ **识别并规整图形**：把手绘的三角形、矩形、圆等识别成标准图形重绘，三角形自动标注三个内角度数和边长
- 📐 **公式可视化**：输入或手写公式（如 `y = x^2 - 2x`、`sin(x)`），自动绘制函数图像（坐标轴、刻度、曲线）

**英语模式**
- ✨ **识别手写单词**：在黑板上手写英文单词，AI 识别
- 🖼️ **单词配图**：AI 生成卡通插图帮助记忆（使用免费的 Pollinations 文生图）
- 🔊 **朗读**：单词和例句都可以点击朗读（浏览器内置语音，免费离线可用）
- 📝 **音标 / 释义 / 例句**：AI 自动生成学习卡片

## 技术方案

| 部分 | 技术 |
|---|---|
| 黑板/手写 | 原生 HTML5 Canvas，无框架无构建 |
| 图形/公式/单词识别 | Claude API 视觉能力（把画布截图发给 Claude，返回结构化 JSON） |
| 角度/边长计算 | 前端本地几何计算（向量夹角） |
| 函数绘图 | math.js 解析表达式 + Canvas 自绘坐标系 |
| 单词配图 | Pollinations 免费文生图 API（无需密钥） |
| 朗读 | Web Speech API（浏览器内置，免费） |
| 后端 | 零依赖 Node 服务器（静态文件 + Claude API 代理，密钥不暴露给前端） |

## 使用方法

```powershell
node server.js
```

浏览器打开 http://localhost:3275 即可。

**AI 额度**：默认走本地 Claude Code CLI（`claude -p`），使用你登录 Claude Code 的订阅额度，**无需 API 密钥**。每次识别约 10~30 秒。
如果设置了 `ANTHROPIC_API_KEY` 环境变量，则自动改走 Anthropic API（按量计费，速度更快）。
