# AI 黑板

一块会讲课的网页黑板:向 AI 老师提问,它像真正的老师一样**一步一步把板书写出来,边写边讲**。

**🔗 在线使用:<https://board.liyucheng.me>**(在「⚙️ 设置」里填自己的 Anthropic API Key,浏览器直连、Key 只存本机)

## 功能

**板书讲解(核心)**
- ✍️ **提问 → 逐步板书**:输入"证明 √2 是无理数""推导求根公式""讲讲 biology 的词源""分析这个句子的语法结构"……AI 流式生成板书,逐字写在黑板上,配语音讲解和字幕
- 📐 **严谨的数学证明**:已知 / 求证 / 证明分层书写,每一步写明依据,KaTeX 公式排版
- 📈 **函数图像与几何图**:讲解中自动画出函数图像(坐标轴、关键点)和几何示意图(标字母、直角/角弧)
- 🔤 **英语词源与语法**:词根词缀拆解卡片、句子成分划分(主语 / 定语从句 / 谓语……)、时态对比表格
- 🖍️ **老师式的板书手法**:多色粉笔区分层次,回头划掉错误想法、框出关键一步
- 🙋 **追问**:讲完给出追问建议;鼠标移到任意一行点「?」可让老师把这一步讲得更细;追问会接着当前板书往下写
- ✏️ **手写提问**:用粉笔把题目写/画在黑板上,勾选「附带手写」后提问,AI 先读懂手写内容再讲解
- ⏯ **播放控制**:暂停 / 直接写完 / 停止 / 重讲,可调速度、难度(小学~大学)、开关语音

**小工具**
- 📐 **规整图形**:把手绘的三角形、矩形、圆等识别成标准图形重绘,自动标注内角和边长
- 📈 **函数图像**:输入框写公式(如 `x^2 - 2x`)或手写公式,直接画出图像
- 🔤 **单词卡**:输入或手写英文单词,生成音标 / 释义 / 例句 / 配图 / 朗读,可一键转到黑板讲词源

## 技术方案

| 部分 | 技术 |
|---|---|
| 模型 | 默认 **Claude Opus 5.5**(`claude-opus-5-5`),可在设置中改模型和思考深度 |
| 板书脚本 | AI 流式输出 NDJSON,每行一个板书动作(`title` / `p` / `math` / `mark` / `plot` / `figure` / `word` / `sentence` / `table` …),前端边收边渲染 |
| 板书渲染 | DOM + KaTeX 公式 + SVG 图形,逐字显现动画;霞鹜文楷字体 |
| 函数图像 | math.js 解析表达式 + SVG 自绘坐标系 |
| 语音讲解 | Web Speech API(浏览器内置,免费) |
| 手写 | 透明 Canvas 叠在板书上方,随板书滚动 |
| 后端 | 零依赖 Node 服务器(静态文件 + Claude 流式代理,SSE) |

板书动作的完整格式见 [public/lesson.js](public/lesson.js) 里的 `lessonSystemPrompt`。

## 使用方法

```powershell
node server.js
```

浏览器打开 http://localhost:3275 即可。

**AI 后端(三级自动切换)**:

1. **同源服务器**(本地 `node server.js`):默认走本地 Claude Code CLI(`claude -p`)订阅额度,**无需 API 密钥**;服务器设置了 `ANTHROPIC_API_KEY` 环境变量则改走 Anthropic API。环境变量 `BOARD_MODEL` 可改服务器默认模型。
2. **访问者本机服务**:在线页面可在设置中开启"优先使用本机 claude 服务",探测本机 `localhost:3275` 是否运行着本项目(CORS 已放行),运行着就用你自己的 claude 订阅额度。
3. **浏览器直连 Anthropic API**:以上都没有时,在「⚙️ 设置」里填 API Key(只存 localStorage,请求由浏览器直发 Anthropic,不经过任何中间服务器)。
